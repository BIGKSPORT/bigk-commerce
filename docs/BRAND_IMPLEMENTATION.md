# BigK identity implementation

Source: **CORPORATE IDENTITY MANUAL BIG K.pdf**, nine pages, provided by the store owner. This document records what the manual specifies and which web-specific decisions were made.

## Official requirements applied

| Source | Manual guidance | Application |
| --- | --- | --- |
| Page 4 | Prefer the typographic version where possible | Official typographic artwork in storefront and page headers; approved white typographic version in the footer |
| Page 5 | Typographic mark, combined signature and symbol | Vector paths extracted from the PDF into `public/brand`; no substitute text logo |
| Page 6 | Approved black, red and white variations | Colour mark on white and white mark on black; symbol-based application icon |
| Page 7 | Protect the logo from surrounding graphics | Dedicated logo container with blank padding; no slogan or icon inserted into that space; aspect ratio preserved |
| Page 8 | “LOOKING GOOD / MOVING FAST” | Official slogan artwork on the brand section, plus the same wording in hero copy, metadata and footer |
| Page 9 | Pantone 185 C, Black C and white | Digital primary colours `#E4002B`, `#2D2926`, `#FFFFFF` |

The old forest/lime palette, text-built “BigK” logo, generic “BK” icon and Georgia display treatment have been removed from the application. Grey interface surfaces are neutral supporting tints, not additional primary brand colours. Product photographs retain their original colours.

## Artwork provenance

Assets use original vector path coordinates from pages 5, 6 and 8. The PDF's screen-rendered CMYK approximations are normalised to the manual's explicit digital HEX values. Paths are not skewed, stretched, re-typeset or generated by an image model. Backgrounds around the artwork are not embedded in the wordmarks, allowing the approved white-background and dark-background uses.

- `bigk-wordmark.svg`: primary colour typographic mark, page 5.
- `bigk-wordmark-white.svg`: approved white typographic mark, page 6.
- `bigk-symbol.svg`, `bigk-symbol-block.svg`: original symbol variants, page 5.
- `bigk-signature.svg`: original combined signature, page 5; available for future placements.
- `bigk-slogan.svg`: official outlined slogan, page 8.
- `public/icon.svg`: original circular symbol in a white square with clear space; no invented letterform.

## Web decisions and remaining approvals

The supplied manual does **not** identify a website font family, font files, font licence, numeric minimum logo size or an explicit numerical definition for the protection unit X. This implementation uses Arial/Helvetica for interface text and a conservative blank margin of half the displayed logo height on all sides. These are documented web decisions, not quoted manual specifications. The logo and slogan themselves remain outlined artwork and do not require a font download.

The diagonal corner accents draw from the manual's page composition. They do not intersect the logo protection area. White text is used on red primary surfaces for contrast; red is not used for small text on black.

Review the final digital placements with the brand owner, especially minimum display sizes. If a supplementary typography or digital-use manual exists, apply it before launch. Product prices, SKU/colour photo mapping, material information and legal policies still require the approvals described in DEPLOYMENT.md.

## Approved website direction

The owner approved the white-led visual preview in this conversation. That direction is now applied to the actual application through `app/identity.css`, loaded after the shared component styles. The hero uses the original page-8 slogan artwork directly, with a white field, red diagonal photo corner and angular calls to action. Compact numbered category links replace the former category tiles. The collection, product dialogs, bag, checkout, account and admin screens use the same heading hierarchy, restrained borders and red accents. The official combined signature appears in the lower brand strip.

The working storefront retains search, comparison, saved products, size selection and the original commerce flows. Production build, TypeScript check, 20 backend tests and isolated storefront browser interactions passed after this design was applied. Desktop/mobile captures in `docs/previews` show the actual component fixture. Full staging end-to-end testing and live launch approval remain outstanding.
